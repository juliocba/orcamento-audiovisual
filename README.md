# SaaS Orçamentos Audiovisuais

Scaffold inicial para uma plataforma SaaS de orçamentos audiovisuais.

Stack: React + Vite + Tailwind + Firebase

Quick start:

```bash
# instale dependências
npm install

# rode em modo dev
npm run dev
```

Configuração do Firebase:

1. Crie um projeto no Firebase
2. Preencha as variáveis em `.env` copiando de `.env.example`
3. Ative Authentication (Google), Firestore e Storage

Deploy:

- Recomendo conectar o repositório à Vercel e definir variáveis de ambiente no painel do Vercel.
